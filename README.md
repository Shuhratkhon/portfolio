# Portfolio

My personal portfolio website: who I am, my skills, projects, achievements and the courses I'm taking.

**Live:** https://shuhratkhon.github.io/portfolio/

## Sections
- Announcement bar and hero with my photo and blue waves around it
- Scrolling strip with the logos of the tools I use
- About and skills (programming languages, data science libraries, web, tools)
- Projects with a screenshot next to each name, big numbers, architecture diagrams for PharmVault, Game Reviews Analysis and Solar System, plus a filter
- Achievements and scores
- Courses roadmap (finished / in progress / planned)
- Beyond code: languages I speak and my hobbies
- Contact

## Built with
- HTML5
- CSS3 (no frameworks, dark space theme with the same falling stars as my course site)
- JavaScript (project filter, fade-in on scroll, active nav link)
- Inline SVG for the diagrams
- Logos from Devicon and Simple Icons (loaded from jsDelivr)
- GitHub Pages for hosting

Made for the Week 10 homework of the Web Programming course at Gachon University.
